# 홈페이지 소개 문구·콘텐츠 구성 소재

> AI 분석 문서. Chart 카드 원문에서 homepage 제작에 쓸 수 있는 **문장 구조와 소재**를 뽑은 것이다.
> 개별 문구는 해당 교육자의 실제 발언/서술이므로, 의뢰 학원장에 그대로 붙여 쓰지 말 것.
> 배운 것: 어떤 "구조"로 자기 이야기를 보여주는가.

## 1. 히어로 한 줄 — 철학 선언형 구조
원문들이 공통으로 쓰는 틀: [반대하는 것] + [지향하는 것] 또는 [정의로부터의 시작].

- "배운 영어가 아니라 실제로 말하는 영어를"… 대비 구조 (id 1)
- "정답 맞히는 기술이 아닌 진짜 실력을" (id 89)
- "문제를 푸는 지식에 머물지 않고 실제로 말할 수 있어야" (id 58)
- "암기한 문법 지식으로 문제만 푸는 대신 문장이 어떻게 만들어졌는지를 먼저 본다" (id 91)
- "점수를 잘 받는 것보다 오래 남는 능력은 혼자서 읽고 이해하고 생각할 수 있는 영어실력" (id 115)
- 경전 인용형: 논어 지지자불여호지자… (id 113)
- 선언·연도 명시형: "스스로 만들지 않은 교재로는 가르치지 않는다 — 2026년 선언" (id 88)

## 2. 섹션 구성 순서 (카드로 확인되는 실제 공개 패턴)
상위권 카드(id 1~20대)의 원문 구성을 역산하면 학원 소개 페이지의 통상 순서와 일치한다:
1) 철학 한 문장 → 2) 진단/입학 방식 → 3) 단계 커리큘럼 → 4) 수업 장면(distinctiveTeaching) →
5) 운영·관리 루틴(테스트·피드백 주기) → 6) 최근 활동/성과(recentActivity) → 7) 강사·채널 정보
→ 8) 상담·등록 유도(카드에는 없으나 설명회·상담 운영 근거: id 90·110·111·113)

## 3. "수업 방식" 섹션 소재 (구체성 순위)
수치·물리 구조가 명시된 카드가 설명력 최상:
- 20분 유닛 인터벌 트레이닝+실시간 구두체크 (id 95)
- PT 입력룸+GT 출력룸 이원 공간 (id 92)
- 4단계 30분 순환(테스트→원어민→문법→복습) (id 63)
- 등원 후 7단계 매일 루틴(단어→집중듣기→ self-reading→영상→스피킹→독해) (id 69)
- i+1 원서 밀당·10분 파닉스·매일 필사 (id 69)
- 설명:수행 4:6 비율 명시 (id 72)
- 일 10분 노출 vs 시험기간 몰아치기 대비 (id 82)

## 4. "관리·피드백" 섹션 소재
- 1·7·30일 누적 반복과 재학습 기준 (id 66) / Power Check 7단계 (id 105)
- 매 수업 1:1 구두 점검+2주 개인 플랜 (id 117)
- 오답노트 재사용·시험지 아카이브 (id 103·70)
- 매일 피드백·수업영상·월간 보고 (id 58)
- 개근 리워드·태도 실력 인정 (id 96)

## 5. "차별화·철학" 텍스트로 쓸 수 있는 원문 문장 구조 (재사용 틀만)
- "우리는 ~하지 않습니다" negatives 선언: 레벨테스트 없음(id 116), 테이블 돌리기 없음(id 90), 없는 이야기 홍보 없음(id 88)
- "사람이 아니라 구조가 성적을 만든다" 시스템 진술 (id 114)
- "강의 이후가 수업의 반" — 과제·오답·이해도 추적 서술 (id 70)
- "이 아이를 위해 만든 경로" — 무학년·1:1 커리큘럼 서술 (id 103)

## 6. 출처·적용 구분 규칙 (Agent 의무)
- 위 인용은 Card 원문 = **해당 교육자 고유 사실**. 예시 틀로만 사용하고 복붙 금지.
- 의뢰 학원장의 실제 정보(이름·수치·프로그램명)가 없으면 해당 슬롯은 섹션 자체를 생성하지 않는다
  (buildit2 최상위 README의 "가짜 정보 생성 금지" 원칙과 동일).
- 다른 교육자 사례를 보여줄 때는 `educators.json` id와 `source.cardUrl`을 각주 형식으로 표기.
