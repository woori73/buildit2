# Wemade 공개 데이터

/wemade 페이지의 공개 분석 데이터를 정제한 공개본입니다.

- **출처**: DART 공시, 언론 보도, 공공 데이터 등 공개 자료
- **정제**: private 저장소의 원본과 동일한 공개 내용입니다. 내부 식별자·비공개 메모가 없음을 확인했습니다.
- **주의**: KIS 실전 시세 원자료, 회원 데이터는 포함되어 있지 않으며 private에 유지됩니다.

## 구조

- `seed/` — 분석용 시드 데이터 (팩트체크, 이벤트, 촉매, 중국 공시/뉴스, 밸류에이션 등)
- `news.json`은 `wemade-news/` 디렉터리에 있습니다.

## 갱신

buildit2 커밋만으로 반영됩니다. Private CI·배포가 발생하지 않습니다.
