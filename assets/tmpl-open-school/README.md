# tmpl-open-school — 종합학원형 멀티섹션 템플릿

## 개요

입시 실적을 전면에 내세운 종합학원 홈페이지 템플릿. 히어로 → 공지사항 → 커리큘럼(초/중/고 탭) → 강사진 → 합격후기 → 상담신청 폼 → 푸터(사업자정보)의 전형적인 학원 사이트 구조를 바닐라 HTML/CSS/JS로 구현.

- ID: `tmpl-open-school`
- 버전: 1.0.0
- 라이선스: **MIT** (이 템플릿의 코드는 100% 신규 작성)

## 파일 구성

| 파일 | 설명 |
|---|---|
| `demo.html` | 독립 실행 데모 (브라우저에서 바로 열기) |
| `style.css` | 전체 스타일 (`bi-` 접두사 네임스페이스) |
| `script.js` | 모바일 메뉴·커리큘럼 탭·스크롤 리빌·카운트업·폼 검증 |
| `README.md` | 이 문서 |

## 사용법

1. `demo.html`을 브라우저에서 엽니다. (빌드 불필요)
2. 학원명·연락처·사업자정보는 `demo.html` 하단 푸터와 상담 폼에서 교체하세요.
3. 실적 숫자(`data-bi-count`), 공지 목록, 커리큘럼 내용은 HTML에서 직접 수정합니다.
4. 색상은 `style.css` 상단 `:root` 변수(`--bi-primary` 등)만 바꾸면 전체 테마가 변경됩니다.

## 주요 특징

- **반응형**: 1120px 컨테이너 → 900px 2열 → 640px 1열, 모바일 햄버거 메뉴
- **한글 최적화**: Noto Sans KR, `word-break: keep-all`
- **접근성**: 시맨틱 태그, 탭 키보드 내비게이션(←/→), `aria-*` 속성, `prefers-reduced-motion` 대응
- **외부 의존성**: Google Fonts(Noto Sans KR) CDN만 사용. 이미지 없음(CSS 아바타)

## 영감 출처

일반적인 학교·학원 웹사이트의 정보 구조(공지/커리큘럼/강사진/후기/상담폼)에서 영감을 받았으나, 마크업·스타일·스크립트는 전부 신규 작성했으며 특정 사이트의 코드를 복사하지 않았습니다.
