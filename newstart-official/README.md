# NewStart 공식 규정 공개 데이터

NewStart 채무조정 서비스의 공식 규정·제도 지식을 정제한 공개 데이터입니다.

- **출처**: 금융위원회, 신용회복위원회, 서민금융진흥원, 새출발기금 등 공공기관 공식 발표
- **정제**: private 저장소의 원본에서 내부 큐레이션 메타데이터(검토 상태·수집 설정·운영자 메모)를 제거한 신규 파일입니다. private Git 기록을 복사하지 않았습니다.
- **용도**: 공개 규정 안내, FAQ 구성 등
- **주의**: 개인정보·상담 사례·운영 DB 정보는 포함되어 있지 않으며, private에 유지됩니다.

## 구조

- `ccrs/` — 신용회복위원회 규정 지식 (k01~k42)
- `fsc/` — 금융위원회 공식 발표
- `hope/` — 서민금융진흥원 공고
- `comparison/` — 제도 비교 매트릭스
- `updates-connect/` — 공식 발표 업데이트
