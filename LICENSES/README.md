## 주의사항

- 각 자산의 원본 저장소에서 최신 라이선스를 확인하십시오.
- anim-slide-in-bottom: 생성된 CSS의 헤더 주석(저작권 고지)을 유지하십시오.
- 라이선스가 불확실한 자산은 `references/`에 링크만 기록되어 있으며, 코드를 포함하지 않습니다.
