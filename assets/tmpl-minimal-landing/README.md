# tmpl-minimal-landing — 미니멀 단일 페이지 랜딩

## 개요

여백으로 말하는 프리미엄 랜딩. 한 화면에 핵심만: 헤드라인 → 3개 강점 → CTA → 푸터.

- ID: `tmpl-minimal-landing`
- 버전: 1.0.0
- 라이선스: **MIT** (이 템플릿의 코드는 100% 신규 작성)

## 파일 구성

| 파일 | 설명 |
|---|---|
| `demo.html` | 독립 실행 데모 (브라우저에서 바로 열기) |
| `style.css` | 전체 스타일 (오프화이트 페이퍼 톤, `bi-` 접두사) |
| `script.js` | 스크롤 등장 페이드 (바닐라 JS, 순차 시차) |
| `README.md` | 이 문서 |

## 사용법

1. `demo.html`을 브라우저에서 엽니다. (빌드 불필요)
2. 헤드라인·강점 문구는 `demo.html`에서 직접 수정합니다.
3. 색상은 `style.css` 상단 `:root` 변수(`--bi-paper`, `--bi-ink`, `--bi-gold`)로 조정합니다.
4. 480px 이하에서는 버튼이 전폭으로 변경됩니다.

## 주요 특징

- **미니멀**: 760px 단일 컬럼, 섹션당 하나의 메시지
- **타이포그래피**: clamp() 유동 타입, 자간 -0.035em의 강한 헤드라인
- **등장 연출**: IntersectionObserver 기반 페이드 + 90ms 순차 시차
- **한글 최적화**: Noto Sans KR(300–900), `word-break: keep-all`
- **접근성**: `prefers-reduced-motion` 시 즉시 표시, 시맨틱 구조
- **외부 의존성**: Google Fonts(Noto Sans KR) CDN만 사용
