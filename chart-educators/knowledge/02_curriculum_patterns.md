# 영어학원 커리큘럼 구성 사례

> AI 분석 문서. 원문 출처는 `../educators.json`의 `card.curriculum` 필드(id 표기). 없는 정보는 추측하지 않았다.

## 1. 학년 연속형 (초등→중등→고등 한 경로)
처음부터 끝까지 하나의 성장 경로로 설계해 "전환"이 아니라 "연속"을 판매포인트로 쓴다.

- 파닉스 → 원서 다독 → 문법노트·라이팅 → 내신 적응까지 장기 단계형 (id 50)
- 초3 기초 완성 → 중등 내신+고등 선행 병행 → 고등 내신·모의고사·수능, 어휘·문법·독해·영작 전 영역 (id 64)
- 중등 내신·Grammar → 고등 Grammar→Reading 단계 연결 (id 60)
- 파닉스→정규반 로드맵, 예비중 특강→보카킹·스피치 콘테스트→NELT·분기 성장기록 (id 107)
- Hooked on Phonics(유치~초2) → 코어(리스닝·리딩·문법 통합) → 중·고등 내신 단일 경로 (id 114)
- 원서 다독·구문독해 누적(초등) → 학교별 시험 보강(중·고) (id 115)

## 2. 진단·레벨링 기반 배치형
입학 시점의 정밀 진단을 커리큘럼의 1단계로 명시한다.

- 지필·구두·파닉스 블렌딩 동시 진단 → 7~10단계 배치, AR·Lexile·음소인식 등 다중 지표 (id 58)
- 인터뷰·레벨테스트 → 일주일 참관수업 → 교사·학생 의견 반영 반 편성 (id 51)
- 어휘·문법·독해·쓰기 4영역 세분화 진단 + 15단계 초정밀 레벨링 (id 87)
- EL·PL·PM·M·K·Y 단계 과정, 학기별 강의 설문 피드백 (id 49)
- 11~15단계 레벨 + 입학 테스트·1:1 인터뷰·단어 즉석 테스트 (id 107)
- 레벨테스트 대신 학부모·자녀 상담으로 시작 (역발배 — id 90), 레벨테스트 자체를 두지 않는 원칙(id 116)

## 3. 개별 맞춤·무학년형
일괄 진도를 명시적으로 거부한다.

- 무학년·무레벨 1:1 개별 커리큘럼, 영역별 개별 진도 (id 103)
- 무학년제 개별 맞춤학습 + 온·오프 원서 루프 (id 111)
- 학생별 이해 속도·취약점을 복습자료·숙제에 반영, 설명:수행=4:6 (id 72)
- 같은 커리큘럼 일괄 적용 지양, 개별 부족분 케어 (id 46)
- 4명 내외 그룹 + 1:1 티코칭 (id 67), 최대 3명·단일 학교 편성 (id 116)
- PSI 개별지도 + 테스트→원어민→문법→복습 4단계 30분 순환 (id 63)

## 4. 자체 제작·교재 완결형
교재를 학원의 산출물로 선언한다.

- "스스로 만들지 않은 교재로는 가르치지 않는다" — 단권화 해설지 + 1만 개 어법코드 (id 88)
- 교재팀이 학교별 변형 대비 자료 직접 제작 (id 97)
- 단권화 교재 + 자체 동형 모의고사, 프랜차이즈 아닌 직접 기획 시스템 (id 98)
- 지역 학교 10년 기출 DB + 자체 변형문제 (id 66)
- 자체 문법 교재·문제은행 배격, 직접 제작 문제 (id 90)

## 5. 입력→출력 루프형
- 매일 원서 1권+자체 워크북 입력, 주 1~2회 원어민 출력, 매일·월간 피드백 (id 58)
- 개별 PT 입력룸 + 그룹 GT 출력룸 이원 공간, 노래·뮤지컬·발표 출력 (id 92)
- 온라인 원서 읽기 9단계 → 오프라인 프랙티스북 확인 루프 (id 111)
- 수업 녹음·판서·쉐도잉·주간 영작 첨삭이 학원 밖으로 이어지는 설계 (id 3)

## 6. 단계 커리큘럼 브랜드화 (프랜차이즈/네이밍형)
- F2R STARTER / BOOSTER / MASTER 3단계 + 학교별 AI 내신 (id 45)
- MILK(유치~초저) / LIME(초고~중등) + 영어글쓰기·뮤지컬 특별과정 (id 85)
- PLA(파닉스)→LA(미국교과서·뮤지컬)→CE(구문·심화) + 복불보카·Grammar Tetris (id 92)
- 12단계·한 단계 4~5개월, 단계 종료=시험이 아닌 공개수업 (id 94)

## Agent 적용 메모
- 커리큘럼 섹션은 위 6개 패턴 중 학원장의 실제 커리큘럼 서술과 맞는 골격을 고르고,
  단계명·주기는 반드시 의뢰 학원장이 제공한 값만 채운다(카드 수치 재사용 금지).
- "누적 테스트 주기"(id 66의 1·7·30일)처럼 구체적 운영 수치는 카드 원본에 있는 경우에만 인용 대상이며,
  타 학원 값이면 예시임을 명시해야 한다.
