# tmpl-demo-school — 모바일 퍼스트 학교형 템플릿

## 개요

모바일 우선으로 설계된 간결한 학원 홈페이지. CSS 변수로 테마를 관리하고 외부 의존성을 최소화.

- ID: `tmpl-demo-school`
- 버전: 1.0.0
- 라이선스: **MIT** (이 템플릿의 코드는 100% 신규 작성)

## 파일 구성

| 파일 | 설명 |
|---|---|
| `demo.html` | 독립 실행 데모 (브라우저에서 바로 열기) |
| `style.css` | 전체 스타일 (CSS 변수 테마, `bi-` 접두사) |
| `script.js` | 폼 검증·전화번호 하이픈 (바닐라 JS, 의존성 없음) |
| `README.md` | 이 문서 |

## 사용법

1. `demo.html`을 스마트폰 브라우저(또는 360px 너비)에서 엽니다.
2. 테마 색상 변경: `style.css` 상단 `:root`의 `--bi-primary`, `--bi-accent` 등 변수만 수정.
3. 시간표·공지·주소는 `demo.html`에서 직접 수정합니다.
4. 데스크톱에서는 480px 앱 프레임으로 중앙 정렬됩니다.

## 주요 특징

- **모바일 퍼스트**: 360px 기준 설계, 큰 터치 영역, 하단 고정 상담 CTA
- **CSS 변수 테마**: 색상·반경·최대너비를 `:root`에서 일괄 관리
- **빠른 메뉴**: 상담 신청 / 시간표 / 오시는 길 3종 바로가기 (인라인 SVG 아이콘)
- **한글 최적화**: Noto Sans KR, `word-break: keep-all`
- **접근성**: `prefers-reduced-motion` 대응, 시맨틱 태그, `env(safe-area-inset-bottom)` 노치 대응
- **외부 의존성**: Google Fonts(Noto Sans KR) CDN만 사용
